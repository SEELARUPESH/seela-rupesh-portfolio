FPGA-Based Traffic Light Controller

Designed an FSM-based controller for a four-way intersection with North-South and East-West emergency vehicle priority. Implemented modular Traffic FSM, Timer and Top modules; verified normal sequencing, emergency handling and safe return to normal operation with a Verilog testbench.

FPGA-Based Digital Voting Machine

Designed a four-candidate voting system using an FSM, push-button debouncing, individual vote counters, simulated EEPROM/Flash storage and winner detection. A 7-segment display presents the winning candidate. Functional simulation and waveform verification were completed.
